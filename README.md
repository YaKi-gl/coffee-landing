## 💡 О проекте

**«Зерно»** — лендинг для небольшой городской кофейни. Его задача — за несколько секунд объяснить гостю, чем это место отличается, показать меню с ценами и дать способ прийти: адрес, часы работы и форма брони столика.

Кофейня вымышленная, но структура и тексты основаны на моём опыте работы в HoReCa с 2022 года: от бариста до управляющего точкой. Я знаю, что гости спрашивают чаще всего, и вынес это на первый экран.

## 🎯 Для кого и зачем

| Кто | Какую задачу решает |
|---|---|
| **Владелец кофейни** | Получает быстрый и недорогой сайт на бесплатном хостинге |
| **Гость** | С телефона за полминуты видит меню и цены, адрес и время работы и может забронировать столик |
| **Маркетолог** | Получает страницу для ссылки из карт, соцсетей и QR-кода на столе |

## 🧭 Структура страницы

| Блок | Компонент | Что в нём | Зачем |
|---|---|---|---|
| **Шапка** | `Nav` | Логотип, якорное меню, тень при прокрутке | Быстрая навигация |
| **Hero** | `Hero` | Оффер, подзаголовок, кнопка «Смотреть меню» | Первое впечатление и главное действие |
| **О нас** | `Features` | 3 преимущества: обжарка, выпечка, атмосфера | Отличие от сетевых кофеен |
| **Меню** | `Menu` | Позиции с ценами в «ресторанном» стиле | Ответ на главный вопрос гостя: сколько стоит |
| **Контакты** | `Contacts` + `BookingForm` | Адрес, часы, телефон, форма брони | Превращает посетителя сайта в гостя |
| **Футер** | `Footer` | Копирайт | Завершение страницы |

## ✨ Возможности

- 📱 **Адаптивная вёрстка**: телефон, планшет, десктоп
- 📝 **Форма бронирования** с валидацией (имя, номер телефона в любом формате), состоянием «отправка» и экраном успеха
- ✏️ **Контент отдельно от вёрстки**: тексты, меню и цены лежат в `src/data/content.js`
- 🔍 **SEO-основа**: `lang`, `meta description`, семантические теги, favicon
- ♿ Анимации отключаются, если в системе включено «уменьшить движение»

## 🎬 Анимации

| Где | Что происходит | Как сделано |
|---|---|---|
| Шапка | Въезжает сверху, получает тень при прокрутке; логотип «покачивается» при наведении | Пружина + хук `useScrolled` |
| Hero | Строки заголовка выезжают из-под маски, фон медленно приближается, кнопка «выпрыгивает» | `overflow: hidden` + `y: 110% → 0`, `scale 1.15 → 1` |
| Преимущества | Карточки появляются по очереди при прокрутке до блока | `whileInView` + `staggerChildren` |
| Меню | Позиции выезжают слева, пунктир «дорисовывается» до цены | `scaleX 0 → 1` с `transform-origin: left` |
| Ошибки формы | Поле «встряхивается», текст ошибки раскрывается | Keyframes `x` + `height: auto` |
| Отправка | Текст кнопки сменяется спиннером | `AnimatePresence mode="wait"` |
| Успех | Круг и галочка рисуются штрихом | SVG `pathLength` 0 → 1 |

## 🛠 Стек технологий

| Слой | Технология | Для чего |
|---|---|---|
| UI | **React 19** | Компонентный интерфейс, хуки `useReducer`, `useMemo`, `useEffect` |
| Анимации | **Framer Motion 12** | Layout-анимации, `AnimatePresence`, пружины, жесты `whileHover` / `whileTap` |
| Сборка | **Vite 7** | Быстрый dev-сервер с HMR и оптимизированная production-сборка |
| Стили | **CSS** (Custom Properties, Grid, Flexbox) | Дизайн-токены, светлая и тёмная тема, адаптив. У каждого компонента свой `.css` |
| Тесты | **Vitest** | Юнит-тесты бизнес-логики и редьюсеров |
| Качество кода | **ESLint** + `eslint-plugin-react-hooks` | Правила хуков и единый стиль |
| CI/CD | **GitHub Actions** → **GitHub Pages** | На каждый push: тесты → сборка → деплой |
| Разработка | **Claude (AI-ассистент)** | Вайбкодинг: генерация и доработка кода по моим требованиям |

## 🏗 Архитектура

```
src/
├── main.jsx · App.jsx            # точка входа и порядок секций
├── data/content.js               # весь контент: тексты, меню, цены, контакты
├── services/
│   ├── booking.js                # валидация и отправка заявки на бронь
│   └── booking.test.js
├── hooks/useScrolled.js          # прокручена ли страница (для шапки)
├── styles/                       # tokens.css (палитра, шрифты) + global.css
└── components/
    ├── Nav/          Nav.jsx + Nav.css
    ├── Hero/         Hero.jsx + Hero.css
    ├── Features/     Features.jsx + Features.css
    ├── Menu/         Menu.jsx + Menu.css
    ├── Contacts/     Contacts.jsx + Contacts.css
    ├── BookingForm/  BookingForm.jsx + BookingForm.css
    ├── Footer/       Footer.jsx + Footer.css
    └── motion/presets.js         # общие анимации появления при прокрутке
```

| Слой | Ответственность |
|---|---|
| `data/` | Контент. Чтобы поменять цену или адрес, не нужно трогать компоненты |
| `services/` | Логика брони без React. Чтобы отправлять заявки в Telegram-бота, достаточно заменить `sendBooking` |
| `components/` | Каждая секция страницы в своей папке со своими стилями (BEM-именование классов) |

## ⚡ Быстрый старт

Нужен [Node.js](https://nodejs.org/) 20 или новее.

```bash
git clone https://github.com/YaKi-gl/coffee-landing.git
cd coffee-landing
npm install
npm run dev        # http://localhost:5173/coffee-landing/
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер с горячей перезагрузкой |
| `npm test` | Запуск юнит-тестов (Vitest) |
| `npm run build` | Production-сборка в `dist/` |
| `npm run preview` | Локальный просмотр собранной версии |
| `npm run lint` | Проверка кода ESLint |

## ✅ Тесты и CI/CD

Покрыта юнит-тестами логика брони (`booking.test.js`): нормализация номера телефона, валидация полей, отправка.

Каждый push в `main` запускает workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml):

```
push → npm install → npm test → npm run build → деплой на GitHub Pages
```

Если хоть один тест падает, сломанная версия на сайт не попадёт.
